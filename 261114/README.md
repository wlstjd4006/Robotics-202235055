# 실습 #1 — 임베디드 시스템과 GPIO 기초

## 1. 학습 내용 및 이론적 배경

- **고수준 제어와 저수준 제어:** 고수준은 센서 데이터를 이용한 인지(Perception), 경로 계획(Planning), 자율주행(Navigation)을 담당한다. 저수준은 MCU를 이용한 모터 출력, 엔코더 처리, 센서 입출력 등을 일정한 주기로 수행한다. 두 제어 계층의 연동이 자율주행 로봇의 기본 구조이다.
- **MCU와 임베디드 시스템:** MCU는 특정 하드웨어를 제어하는 소형 컴퓨터로, Arduino와 ESP32 등이 있다. RTOS는 실시간성이 필요한 제어 작업을 관리하는 데 활용된다.
- **Linux와 CLI:** Ubuntu는 Linux 기반 운영체제이며 ROS2 개발 환경에서 널리 사용된다. `~`는 홈 디렉터리, `/`로 시작하는 경로는 절대경로, 그 외의 경로는 상대경로이다.
- **전자회로 관련:** 옴의 법칙 `V = IR`에 따라 전압·전류·저항이 움직인다. 부품 간의 통신을 위해서는 Common Ground가 중요하다.
- **GPIO:** 범용 입출력 핀으로, `INPUT`은 버튼과 센서의 신호를 읽고, `OUTPUT`은 LED 등의 장치를 제어한다. HIGH, LOW는 디지털 논리 수준이며 실제 전압은 보드에 따라 다르다.
- **아날로그와 디지털:** 아날로그는 연속적인 값, 디지털은 이산적인 값으로 표현된다. ADC는 아날로그 신호를 디지털 값으로, DAC는 디지털 값을 아날로그 신호로 변환한다.

## 2. 실습 내용 및 핵심 기술

`tinkercad.cpp`에서 7번 핀을 출력으로 설정하고, `digitalWrite()`로 LED를 제어했다.

1. `pinMode(7, OUTPUT)`으로 LED 핀을 출력 모드로 설정한다.
2. `digitalWrite(7, HIGH)`로 LED를 켜고 `delay(1000)`으로 1초 대기한다.
3. `digitalWrite(7, LOW)`로 LED를 끄고 다시 1초 대기한다.
4. 위 과정을 `loop()`에서 반복한다.
